Introduction
I collected 100 rows of data from the open meteo api for nairobi kenya from 1st may 2026 to 24th august 2026.
The data was collected in json format and converted to a pandas dataframe.
The dataframe was then cleaned by renaming the columns, converting the date column to datetime format, and extracting the month from the date column.
The cleaned dataframe was then saved to a csv file named nairobi_weather_cleaned.csv.
The dataframe was then analyzed by calculating the value counts and mode for the month column, calculating the skewness for the numeric columns, calculating the correlation matrix for the numeric columns,
 and calculating the average temp_max_c by month using groupby.
